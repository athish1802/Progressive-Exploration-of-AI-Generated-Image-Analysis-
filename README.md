# Progressive Exploration of AI-Generated Image Analysis

## Presenting Gender Differences and Stereotypes in Text-to-Image Models

This repository accompanies the research paper:

> **Progressive Exploration of AI-Generated Image Analysis: Presenting Gender Differences and Stereotypes in Text-to-Image Models**

## Status

This paper was presented at **IConIC, Chennai, India, in 2024**. Publication in Scopus-indexed proceedings is pending.

## Overview

This research examines gender differences and stereotypes in AI-generated images produced by text-to-image models. It explores how prompt design and model outputs can reveal or reinforce demographic bias, with implications for responsible AI, fairness, and human-centered system design.
